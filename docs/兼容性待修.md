## 1. 已修（4 条）

### 1.1 共产国际脚本缺一个闭合括号 → 整文件解析失败

- **提交**：`e9c4bbe`
- **文件**：`common/scripted_effects/TNO_Comintern_scripted_effects.txt`
- **改动**：第 183 行（外层 `if` 结束）之后补一个 `}`
- **根因**：LFB 用 game rule（`LFB_SocIntern_status` / `LFB_SOCINTERN_ENABLED`）把原版逻辑整个包了一层，改写时漏了外层 effect 的右括号，文件最终深度为 1。导致 `TNO_run_socintern_script` 之后的六个 effect（`SocIntern_Tabulate_Votes` / `Vote_Pass_Effects` / `Vote_Fail_Effects` / `Clear_Vote_Effects` / `Refresh_Arrays` / `Change_Leader`）全被嵌进它内部，不再是顶层 effect。
- **验证**：errors 778 → 777，新增 0；`hoi4_lint.py` 独立复核同样只少这一条 `syntax.parse`。

### 1.2 国家概况（开屏）正文全部显示原始本地化键

- **提交**：`cac8745`
- **文件**：`common/scripted_guis/TNO_Country_Info_Screen.txt`
- **改动**：在 `center_title_visible` 触发块末尾补回一行 `set_temp_variable = { f = CountryInfo_Selected }`（4 Tab 缩进，与 TNO 原版第 358 行逐字符一致）
- **根因**：TNO 原版靠这一行在每次 GUI 刷新时把显示索引 `f` 同步成 `CountryInfo_Selected`。LFB 在同一段 hunk 里加「社交媒体按钮」时把它连带删了。于是 `f` 停在默认值 `0`，正文去取 `COX_CountryInfo_Content.0`。
- **关键证据**：`_CountryInfo_Content.0` 这种键在**本仓库、TNO、汉化三层都不存在**（递归统计均为 0 个），只有 `.1`～`.8`，所以界面直接显示 `==COX_CountryInfo_Content.0==`。左侧目录不受影响，因为它走另一条路径另行设置 `f`。
- **验证**：errors/warnings 均无变化（777/1823），新增 0。
- **⚠ 未实机确认**：静态校验不建模 scripted GUI 触发器里的副作用。需要进游戏打开任意国家「国家概况」，确认正文恢复中文。

### 1.3 `LFB_COX_catego.txt` 里 `NOT` 后缺块 → 整文件解析失败

- **改动**：第 143 行 `NOT = has_country_flag = Shaanxi_gui_hidden` → `NOT = { has_country_flag = Shaanxi_gui_hidden }`
- **根因**：`NOT` 是块式触发器，裸赋值让解析器在该行报错，整个分类文件失效——`COX_Liberate_Shaanxi` 及其余分类全部不注册。
- **验证**：`hoi4_lint.py` 的 `syntax.parse` 从有到无；新增问题 0。

### 1.4 `LFB_COX_dec.txt` 地区整合块只注了一半 → 整文件解析失败

- **改动**：第 572～721 行（`COX_coring_integrate_nanjiang` 南疆决议 + 收尾 `}`）行首统一加 `#`，共 150 行。
- **根因**：`git blame` 显示 572/721 行来自 2024-02-19 的原版 `TNO_COX_dec.txt`，从未被改；2026-05-06 的 `b36d466`「事件 土改决议调整」只把 491～571 行（外层 `COX_coring_category = {` 与北疆决议）注掉，漏了南疆决议。外层 `{` 消失后，第 721 行就成了**多余右括号**。
- **为什么不是「直接删掉 721 行」**：`decisions/*.txt` 的顶层键是决议分类，删括号会让南疆决议变成顶层块、指向不存在的分类。同批改动还把 `LFB_decisions_l_simp_chinese.yml:96/97/100/101` 与 `LFB_COX.txt:1237` 的 unlock 提示一并注掉，三处一致表明整套「地区整合」内容被**有意停用**，因此按「把停用做完」处理。
- **若要恢复南疆决议**：解注 491 行 + 解注中文本地化对应条目 + 去掉 572–721 的注释前缀，属功能改动。
- **验证**：`syntax.parse` 清零；两套校验器均新增 0（详见第 5 节）。

## 3. 已知误报（不必处理）

- `hoi4skill` 报的「focus … missing `ai_will_do`」「missing `relative_position_id`」共 1752 条：那是它按自己生成模板给的建议，不是游戏报错，TNO 风格国策本来就不写这些。
- `hoi4_lint.py` 的 `mod.sibling_mod_missing`：只在 A/B 对比用不同文件夹名时出现，实际运行时选中的 `.mod` 存在即无事。
- 汉化包（`2243912940`）文件夹内的 `descriptor.mod` 里 `path=` 指向上传者机器的 `E:/Game/HOI4/TNOCN`，游戏不读它（读的是启动器目录里的 `.mod`），不影响加载。
