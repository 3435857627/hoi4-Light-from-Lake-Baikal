## 1. 树结构总览

- 树 id：`XBJ_Qinghai_emergency`（青海危机），共 **13 个国策**，**无互斥分支**。
- 层级：
  1. `渗透火药桶`（第 1 层，唯一入口）
  2. 三条调查线：`我们保护贫苦的人民` / `我们带来和平与安定` / `我们带着充饥的粮食`（三条**全部**是下一层的前置）
  3. `支援马敦靖`（cost 1，7 天）
  4. `尘埃落定`（`available = { always = no }`，只能靠 bypass：QIN 不存在时完成）
  5. 五条建设线：`接管破产商会` / `新疆土改的经验` / `国有化湟中实业` / `清扫流寇` / `打击门阀`（五条**全部**是下一层的前置）
  6. `青海人民政府`
  7. `防范东部之敌`
- **顺跑总时长：175 天**（14 + 14×3 + 7 + 14 + 14×5 + 14 + 14）。
- 若 `尘埃落定` 走 bypass（QIN 被灭）：**161 天**。
- **11 个国策带 `bypass = { hidden_trigger = { has_war_with = GAN } }`**（GAN = 西北绥靖公署）。与 GAN 交战时，除 `青海人民政府`、`防范东部之敌` 外都能 bypass 跳过（跳过即视为完成、照给奖励），理论最快约 **28 天**（14 + 14）。
- 全树没有任何 `mutually_exclusive`。

## 4. 结论 / 待确认

> **2026-11-10 修正**：危机行动 11（召集边防民兵）/ 12（筹措军备）的状态判定原本写 `state = 2022`——2022 不在危机地图数组里（TNO 1.10 里它是南极「Ronne Ice Shelf」），按钮永远不会出现。已把 `update_task` 里 12 处 `state = 2022` 改为 `state = 2433`（焉耆，危机数组中代表新疆的后方州，`controller = 4`），并把 `XBJ_NWC_Getregion_XJ` 的「新疆」标签同步改为 2433。编制与数量未改动。

1. **PP 奖励**：10 个国策各 +30 PP（合计 300 PP；`尘埃落定`、`青海人民政府`、`防范东部之敌` 不给），`接管破产商会` 另给一次性 GDP +5% 与增长 +1；其余全是「解锁行动 + 剧情事件」。
2. **`国有化湟中实业` 目前没有机械奖励**（经济效果被注释），是本树最大的空奖励点。
3. **`清扫流寇` 的事件选项是 `add_manpower = 1`**（1 人力），与「+950 人力」的后续行动不匹配，疑似占位或笔误。
4. **`支援马敦靖` 的奖励事件受 `fire_only_once` 影响**：正常流程里危机行动 [5] 会先触发 XBJ.5，导致焦点本身不再跑马惇靖/内战 setup（只剩开锁 [11][12]）。若期望「点国策才开内战」，需要把行动 [5] 的事件改成别的链或去掉该焦点的事件触发。
5. **`尘埃落定` 不能正常点**（`available = always = no`），完全依赖 bypass；实际游戏中应在 QIN 灭亡后自动完成。
6. 全树无互斥；三条调查线、五条建设线都必须全做才能推进，因此顺跑 175 天是设计值，战时 bypass 可压到 28 天左右。
7. 时间计算未考虑国策速度修正与 bypass；TNO 的国策保存进度上限为 20（`MAX_SAVED_FOCUS_PROGRESS`）。

1. **「分配土地」建模板的判定（已修）**：原来写的是 `NOT = { has_template = "Infantry Division" }`，2026-11-10 改为 `"Red Guards"`——同一局里只在第一次分配土地时建模板，之后各州复用，不会再重复建同名模板。
