## 3. 已知误报（不必处理）

- `hoi4skill` 报的「focus … missing `ai_will_do`」「missing `relative_position_id`」共 1752 条：那是它按自己生成模板给的建议，不是游戏报错，TNO 风格国策本来就不写这些。
- `hoi4_lint.py` 的 `mod.sibling_mod_missing`：只在 A/B 对比用不同文件夹名时出现，实际运行时选中的 `.mod` 存在即无事。
- 汉化包（`2243912940`）文件夹内的 `descriptor.mod` 里 `path=` 指向上传者机器的 `E:/Game/HOI4/TNOCN`，游戏不读它（读的是启动器目录里的 `.mod`），不影响加载。
- 「authoring placeholder `【…】`」23 条：校验器把所有 `【】` 当成 AI 待填占位符，本模组是拿它当强调括号
  （如 `【粉碎水霸】`、`【民兵】`），中文排版里正常显示，**不是缺陷**。
- 「colour reset `§!` has no preceding colour code」24 条：校验器按栈式嵌套判断，而 HOI4 是
  「新颜色直接覆盖旧颜色」，`§F…§G…§!` 这种写法合法，改掉反而会破坏原文。
- 「focus_tree … has an invalid country selector」139 条：要求 `country = { factor = 0 modifier = { add = 10 tag = X } }`
  这一种写法；TNO 体系用的是自己的形式，游戏能读，属风格差异。
